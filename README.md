Clinic Management là ứng dụng web quản lý phòng khám, được xây dựng bằng Java Servlet, JSP, JDBC và SQL Server theo mô hình MVC. 
Hệ thống hỗ trợ ba vai trò: bệnh nhân, bác sĩ và quản lý. 
Bệnh nhân có thể đặt lịch và xem hồ sơ khám;
bác sĩ quản lý lịch hẹn, ghi nhận kết quả khám, kê đơn và xác nhận thanh toán; quản lý theo dõi hoạt động phòng khám,
quản lý tài khoản và thống kê doanh thu.
